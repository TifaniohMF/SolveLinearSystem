# Contribution
1. Fork this repository
```bash
git clone git@githu.com:TifaniohMF/SolveLinearSystem.git
cd SolveLinearSystem
```

2. Create a branch 
```bash
git checkout -b feat/add-modif
```

3. Commit your change
```bash
git commit -m "feat: add feature"
```

4. Push
``bash
git push origin feat/add-modif
```

5. Open a **pull request**
